# Mod List

!!! abstract "Quick facts"
    - The published world already has every mod it needs.
    - Adding the scenario to your own world: add **Required** and **World rules**. Each brings in its own
      requirements, so you don't add those yourself.

## Required

| Mod | Workshop | What it does here |
|---|---|---|
| WW2-WitM-MES | [3793633400](https://steamcommunity.com/sharedfiles/filedetails/?id=3793633400) | The encounters: ships, aircraft, ground vehicles, ports, airfields, garages and hangars. Brings in the Framework and every weapon and part pack the vehicles use. |
| WW2-WitM-Planet | [3788435958](https://steamcommunity.com/sharedfiles/filedetails/?id=3788435958) | The Mediterranean planet with its historic locations and roads. |
| Fletcher Armaments [Weaponcore Edition] | [2844434226](https://steamcommunity.com/sharedfiles/filedetails/?id=2844434226) | Naval guns on the warships. |
| (IAP) Inconvenient Additions Pack | [2883075089](https://steamcommunity.com/sharedfiles/filedetails/?id=2883075089) | Blocks used by several vehicles. |
| ModAdjusterV2 | [3017795356](https://steamcommunity.com/sharedfiles/filedetails/?id=3017795356) | Applies the Framework's tech costs. |
| AiEnabled | [2596208372](https://steamcommunity.com/sharedfiles/filedetails/?id=2596208372) | Bot crews. |
