# Playing on the Server

!!! abstract "Quick facts"
    - Campaign 1 is a **public season** of War in the Mediterranean, open to everyone.
    - It runs on the MNGC group's dedicated server.
    - **Join details are not on this wiki.** They are posted in the WitM Discord.
    - The server uses the same mods and rules as the published world, with a few server-only settings below.

## Joining

Server address, password and play times are posted in the WitM Discord. This wiki is public, so they are kept there.

## How the server differs from the published world

- Custom turret controllers (CTCs) are not available to players.
- NPC turret ranges are set for the server.
- The server runs Torch with a fixed plugin set, including offline protection for bases.

!!! note
    The mod author keeps this list short and current. If something on the server behaves differently from this wiki,
    the server is right and the wiki needs fixing.
